# MyVM ImGui 教学工作台设计

## 目标

为 MyVM 增加一个原生 C++ 桌面教学工具，用真实汇编器生成字节码，并驱动真实 VM 做单步和连续执行。用户能同时观察源代码、指令字节、寄存器、数据暂存器、地址暂存器、内存、栈和最近执行记录。

## 架构

- `myvm-lab-core` 是不依赖 GUI 的 C++23 模型层，直接链接现有 `myvm-assembler` 和 `vmlib`。它负责汇编、VM 生命周期、单步/限量运行、复位、反汇编行描述和执行历史。
- 在 VM 核心增加只读调试快照接口，安全地返回 VMState、数据暂存器和已初始化地址暂存器的地址/值。快照只允许在 VM 未执行时取得。
- `myvm-lab` 使用 Dear ImGui 原生 C++ API、SDL2 和 OpenGL3 后端。源码编辑与诊断、反汇编/控制流、寄存器与暂存器、内存与栈、执行历史组成工作区。
- CMake 选项 `MYVM_BUILD_LAB` 控制 GUI 和 Dear ImGui 获取；默认关闭，避免核心库构建依赖窗口系统。`BUILD_TESTING` 下始终构建 GUI 无关的模型测试。

## 交互与数据流

1. 编辑器中的汇编文本交给现有 `Assembler::assemble`。成功时保留原始字节码并创建新的 VM 会话；失败时显示源文件、行、列和错误信息，保留当前可运行会话。
2. VM 会话持有稳定地址的可写内存：汇编产物在前，后接栈空间。通用寄存器 0 从程序偏移 0 开始；寄存器 3 指向栈顶。VM 仍使用原有字节码和执行逻辑。
3. 单步执行调用 `MVM::run(1)`，之后读取调试快照并记录前后 PC、操作码、数据暂存器和步数。连续执行按帧限量推进，遇到 `pause`、错误或程序边界时自动暂停。
4. 复位从相同字节码重新创建 VM。内存和栈地址以程序内相对偏移显示；寄存器中的非程序指针以十六进制显示。

## 教学视图

- 顶部工具栏：汇编/加载、复位、单步、运行/暂停、每帧执行量和源文件路径。
- 左侧：汇编源码和带行列的诊断。
- 中央：按 8 字节指令解码的列表，突出当前 PC，显示原始字节、助记符、操作数和简短语义。`leamem` 后的 8 字节地址字面量作为数据行显示，不误解为指令。
- 右侧：通用寄存器、专用寄存器说明、`currdata`、标志位以及已初始化地址暂存器。
- 底部：内存十六进制视图、栈指针位置和最近执行记录。

## 错误处理

- 汇编失败不会替换当前 VM 会话。
- VM 执行异常会暂停连续执行并显示错误，不继续执行后续帧。
- 地址暂存器快照只读取 VM 通过 `leareg`/`leamem` 建立的有效引用；调试快照遇到执行中的 VM 时返回明确错误。
- 窗口、OpenGL 或 SDL 初始化失败时输出可读错误并以非零状态退出。

## 验证

- C++ 单元测试覆盖：调试快照中的数据暂存器和地址暂存器值、汇编诊断失败时保留活动会话、单步更新 PC/寄存器/历史、`leamem` 数据槽正确解码、复位重现初始状态。
- 标准 CMake/CTest 继续验证原 VM 与汇编器；启用 GUI 后构建 `myvm-lab`。
- 在本地 SDL2/OpenGL 环境启动 GUI，执行内置演示程序并逐步验证状态面板；记录未能自动化的显示驱动限制。

## 非目标

首版不做异步 VM worker、插件端口配置界面、源码调试符号、反向执行、项目管理或完整 IDE 功能。连续运行通过同步限量执行实现，保持教学观察的确定性。
