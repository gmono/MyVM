# MyVM 指令集说明

本文描述 `vmlib` 当前实现的字节码格式和指令行为。指令编号及行为以 `mvm_execute.cpp` 中的解释器为准。

## 指令格式

- 每条指令固定为 8 字节，不使用变长编码。
- 第 0 字节是操作码，操作码编号见下表。
- 多字节整数采用小端序。
- 未列出的保留字节应置零。
- 除 `leamem` 后的 8 字节地址数据外，解释器按每次 8 字节递进程序计数器。
- 指令操作的数据来自数据暂存器 `currdata`；需要地址暂存器时由 `leareg` 建立地址引用。

## 寄存器与暂存器

通用寄存器均为 8 字节。部分编号有固定用途：

| 编号 | 用途 |
| --- | --- |
| 0 | 程序计数器，保存当前指令地址 |
| 1 | 中断向量表地址 |
| 2 | 中断向量表项数 |
| 3 | 栈指针 |
| 4 | 标志寄存器 |

`currdata` 是 8 字节数据暂存器。`leareg` 建立的地址暂存器由独立的暂存器编号索引，指令操作它们指向的 8 字节数据。

## 指令表

| 操作码 | 助记符 | 操作数字节 | 行为 |
| --- | --- | --- | --- |
| `0x00` | `rupt id` | 4–7：中断向量号 `dword` | 触发内部中断。保存后续指令地址并跳转到对应中断向量。若已经在中断处理中则不再嵌套触发。 |
| `0x01` | `leareg regid, id` | 2–5：寄存器编号 `dword`；6–7：地址暂存器编号 `word` | 将通用寄存器 `regid` 的地址放入地址暂存器 `id`。 |
| `0x02` | `leamem id` | 6–7：地址暂存器编号 `word` | 将下一条 8 字节数据作为程序内存中的 8 字节槽位索引，写入地址暂存器 `id`；该索引按 8 字节单位换算为地址，该数据槽不作为指令执行。 |
| `0x03` | `ld id` | 6–7：地址暂存器编号 `word` | 从地址暂存器指向的位置读取 8 字节到 `currdata`。 |
| `0x04` | `ldl data` | 4–7：立即数 `dword` | 替换 `currdata` 的低 32 位，保留高 32 位。 |
| `0x05` | `ldh data` | 4–7：立即数 `dword` | 替换 `currdata` 的高 32 位，保留低 32 位。 |
| `0x06` | `save id` | 6–7：地址暂存器编号 `word` | 将 `currdata` 的 8 字节写入地址暂存器指向的位置。 |
| `0x07` | `add id` | 6–7：地址暂存器编号 `word` | 将 `currdata` 加到地址暂存器指向的 8 字节无符号整数。 |
| `0x08` | `dec id` | 6–7：地址暂存器编号 `word` | 从地址暂存器指向的 8 字节无符号整数中减去 `currdata`。 |
| `0x09` | `mul id` | 6–7：地址暂存器编号 `word` | 将地址暂存器指向的 8 字节无符号整数乘以 `currdata`。 |
| `0x0A` | `div id` | 6–7：地址暂存器编号 `word` | 将地址暂存器指向的 8 字节无符号整数除以 `currdata`；除数为零时触发中断 1。 |
| `0x0B` | `cmp id` | 6–7：地址暂存器编号 `word` | 比较 `currdata` 与地址暂存器指向的 8 字节无符号整数，并更新标志寄存器的低两位。 |
| `0x0C` | `pause` | 无 | 进入暂停状态并调用暂停回调。 |
| `0x0D` | `step` | 无 | 将当前步数加一。 |
| `0x0E` | `jmp` | 无 | 跳转到 `currdata` 指定的地址。 |
| `0x0F` | `asjmp condition` | 7：条件值 `byte` | 若 `condition` 的低两位等于标志寄存器的低两位，则跳转到 `currdata` 指定的地址。 |
| `0x10` | `push` | 无 | 将 `currdata` 压入栈，并向低地址移动栈指针 8 字节。 |
| `0x11` | `pop` | 无 | 从栈顶弹出 8 字节到 `currdata`，并向高地址移动栈指针 8 字节。 |
| `0x12` | `read id` | 4–7：端口编号 `dword` | 从端口读取数据到 `currdata`。 |
| `0x13` | `write id` | 4–7：端口编号 `dword` | 将 `currdata` 的低 32 位写入端口。 |
| `0x14` | `call` | 无 | 将返回地址压栈，然后跳转到 `currdata` 指定的地址。 |
| `0x15` | `ret` | 无 | 从栈中弹出返回地址并跳转。 |
| `0x16` | `iret` | 无 | 结束中断状态，并按 `ret` 的方式恢复返回地址。 |

当前实现共定义 23 条指令，操作码范围为 `0x00`–`0x16`。

## 比较标志

`cmp id` 比较 `currdata` 与地址暂存器指向的值。它先清除标志寄存器的低两位，再写入比较结果：

| 低两位 | 含义 |
| --- | --- |
| `00` | `currdata` 小于目标值 |
| `01` | 两者相等 |
| `10` | `currdata` 大于目标值 |
| `11` | 当前比较指令不会产生此值 |

`asjmp` 使用条件字节的低两位与该比较结果进行相等匹配。

## 中断编号

| 编号 | 原因 |
| --- | --- |
| `0` | 无效指令 |
| `1` | 除数为零 |
| `2` | 端口不存在或端口未提供可读数据 |
| `3` | 寄存器编号或内存引用无效 |
| `4` | 中断向量号超出向量表范围 |

内部中断由 `rupt` 指令或运行时错误触发。外部中断通过 VM API 请求，在解释器检查中断请求时处理，不直接改写当前指令地址。
